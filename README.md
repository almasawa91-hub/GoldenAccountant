# المحاسب الذهبي — Golden Accountant

تطبيق محاسبي عربي Offline-first مبني بـ Kotlin وJetpack Compose وRoom.

## المبدأ
- لا توجد بيانات تجريبية.
- الأرصدة ناتجة عن الرصيد الافتتاحي والحركات الفعلية.
- القيود مزدوجة: إجمالي المدين = إجمالي الدائن.
- العمليات المالية تُنفذ داخل معاملات ذرية.
- التطبيق يعمل محليًا أولًا ولا يعتمد على الإنترنت لتسجيل العمليات.

## المرحلة الحالية
تأسيس مشروع Android قابل للبناء سحابيًا، مع نواة قاعدة البيانات والمحرك المحاسبي وواجهة عربية RTL. ستتوسع المزايا على دفعات مع اختبارات لكل عملية محاسبية.
